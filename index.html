1. Builder Pattern Creational Design Pattern

Builder Pattern adalah design pattern creational yang memungkinkan pembuatan objek kompleks secara bertahap. Pattern ini memisahkan proses konstruksi dari representasi akhir objek, sehingga proses pembuatan yang sama bisa menghasilkan representasi objek yang berbeda.

📁 builder_pattern.dart
// ==========================================
// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A
// ==========================================

class Config {}

class ConfigBuilder {
  ConfigBuilder host(String h) {
    print("Host : $h");
    return this;
  }

  ConfigBuilder port(int p) {
    print("Port : $p");
    return this;
  }

  Config build() {
    print("Config berhasil dibuat");
    return Config();
  }
}

void main() {
  ConfigBuilder()
      .host('localhost')
      .port(8080)
      .build();
}

2. Masalah Tanpa Extension Methods Sebelum Extension

Extension Methods adalah fitur dalam bahasa pemrograman yang memungkinkan kita menambahkan fungsi baru ke tipe data yang sudah ada, tanpa harus mengubah kode asli dari tipe data tersebut.

📁 tanpa_extension.dart

// NIM   : 251410020

class StringUtils {
  static String capitalize(String text) {
    if (text.isEmpty) return text;
    return text[0].toUpperCase() + text.substring(1);
  }

  static bool isEmail(String text) {
    return text.contains('@');
  }
}

void main() {
  var name = 'john';
  var capitalized = StringUtils.capitalize(name);
  var isEmail = StringUtils.isEmail('test@mail.com');
  
  print('Original name : $name');
  print('Capitalized    : $capitalized');
  print('Is Email       : $isEmail');
}

3. Solusi dengan Extension Methods Dengan Extension

Extension Methods adalah fitur yang memungkinkan kita menambahkan method baru ke tipe data yang sudah ada tanpa harus mengubah kode aslinya. Ini adalah solusi elegan untuk masalah-masalah yang sebelumnya dihadapi.

📁 dengan_extension.dart
// ==========================================
// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A
// ==========================================

extension StringExtensions on String {
  String capitalize() {
    if (isEmpty) return this;
    return this[0].toUpperCase() + substring(1);
  }

  bool get isEmail => contains('@');

  String reverse() {
    return split('').reversed.join();
  }
}

void main() {
  var name = 'john';
  var capitalized = name.capitalize();
  var isEmail = 'test@mail.com'.isEmail;
  var reversed = 'hello'.reverse();
  
  print('Original name : $name');
  print('Capitalized    : $capitalized');
  print('Is Email       : $isEmail');
  print('Reverse hello  : $reversed');
}

4. Sintaks Extension Methods Cara Penulisan

Extension Methods memungkinkan Anda menambahkan fungsi baru ke tipe data yang sudah ada dengan sintaks yang sederhana dan mudah dipahami.

extension DateTimeExtensions on DateTime {
  // Method
  String toFormattedString() {
    return '$day/$month/$year';
  }

  // Getter
  bool get isToday {
    var now = DateTime.now();
    return year == now.year && month == now.month && day == now.day;
  }

  // Operator
  DateTime operator +(Duration duration) {
    return add(duration);
  }
}

void main() {
  DateTime today = DateTime.now();
  print('Tanggal hari ini        : ${today.toFormattedString()}');
  print('Apakah hari ini?        : ${today.isToday}');
  DateTime nextDay = today + Duration(days: 1);
  print('Tanggal setelah ditambah: ${nextDay.toFormattedString()}');
}

5. Extension untuk Null Safety Nullable Types

Null Safety Extension adalah extension method yang dirancang khusus untuk menangani tipe data yang mungkin bernilai null (nullable types). Extension ini membantu kita mengelola nilai null dengan aman tanpa harus menulis kode pengecekan if (value == null) berulang-ulang.

📁 null_safety.dart
// ==========================================
// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A
// ==========================================

extension NullableStringExtensions on String? {
  String orEmpty() => this ?? '';
  bool get isNullOrEmpty => this == null || this!.isEmpty;
  bool get isNotNullOrEmpty => !isNullOrEmpty;
  String withDefault(String defaultValue) {
    return this ?? defaultValue;
  }
}

void main() {
  String? name;
  print('Hasil orEmpty()            : ${name.orEmpty()}');
  print('Hasil isNullOrEmpty        : ${name.isNullOrEmpty}');
  print('Hasil isNotNullOrEmpty     : ${name.isNotNullOrEmpty}');
  print('Hasil withDefault("Guest") : ${name.withDefault('Guest')}');
}

6. Utilities untuk Dart Types PRAKTEK 1

Membuat extension methods sebagai utilities untuk tipe data bawaan Dart (String, int, double, bool, List, Map) agar kode lebih bersih, reusable, dan mudah digunakan.

📁 number_extensions.dart
// ==========================================
// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A
// ==========================================

extension NumberExtensions on num {
  // Format ke Rupiah
  String toRupiah() {
    return 'Rp${toStringAsFixed(0)}';
  }

  // Cek nilai dalam range
  bool isBetween(num min, num max) {
    return this >= min && this <= max;
  }

  // Pangkat
  num power(int exponent) {
    var result = this;
    for (var i = 1; i < exponent; i++) {
      result *= this;
    }
    return result;
  }
}

void main() {
  var price = 150000;
  print('Harga dalam rupiah : ${price.toRupiah()}');
  print('Apakah antara 1-10 : ${5.isBetween(1, 10)}');
  print('Hasil 2 pangkat 3  : ${2.power(3)}');
}

7. Generic Extensions Generic

Generic Extensions adalah fitur yang memungkinkan kita membuat extension method yang bisa bekerja pada berbagai tipe data sekaligus, tanpa harus menulis ulang kode untuk setiap tipe.

📁 generic_extensions.dart
// ==========================================
// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A
// ==========================================

extension ListExtensions on List {
  // Mengambil index dengan aman
  T? getOrNull(int index) {
    if (index < 0 || index >= length) return null;
    return this[index];
  }

  // Membagi list menjadi beberapa bagian
  List> chunk(int size) {
    var chunks = >[];
    for (var i = 0; i < length; i += size) {
      chunks.add(sublist(i, i + size > length ? length : i + size));
    }
    return chunks;
  }

  // Menghapus data duplikat
  List distinct() {
    var result = [];
    for (var item in this) {
      if (!result.contains(item)) result.add(item);
    }
    return result;
  }
}

void main() {
  var numbers = [1, 2, 3, 4, 5, 6, 7];
  print('Data chunk : ${numbers.chunk(3)}');
  print('Data distinct : ${[1, 2, 2, 3, 3].distinct()}');
}

9. Konflik Nama Extension Resolusi Konflik

Konflik nama terjadi ketika dua atau lebih ekstensi (baik yang bernama maupun tidak bernama) memiliki nama method, getter, atau operator yang sama untuk tipe yang sama, dan cakupannya (scope) saling tumpang tindih.

📁 konflik_extension.dart
// ==========================================
// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A
// ==========================================

// Extension pertama
extension StringCaseExtensions on String {
  String capitalize() {
    return "${this[0].toUpperCase()}${substring(1)}";
  }
}

// Extension kedua
extension TextUtilsExtensions on String {
  String capitalize() {
    return ">>> ${toUpperCase()} <<<";
  }
}

void main() {
  var text = 'hello';
  // Menggunakan extension pertama
  print(StringCaseExtensions(text).capitalize());
  // Menggunakan extension kedua
  print(TextUtilsExtensions(text).capitalize());
}

10. Extension untuk Custom Classes User Defined

Extension adalah fitur di Dart yang memungkinkan Anda menambahkan fungsionalitas baru (method, getter, setter, operator) ke tipe data yang sudah ada (baik bawaan seperti String/int, maupun class custom) tanpa harus mengubah kode aslinya.

📁 custom_class.dart
// ==========================================
// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A
// ==========================================

class Product {
  final String name;
  final double price;
  Product(this.name, this.price);
}

// Extension format Rupiah
extension DoubleRupiahFormatter on double {
  String toRupiah() {
    final intValue = toInt();
    String numberString = intValue.toString();
    String formattedString = '';
    int counter = 0;
    for (int i = numberString.length - 1; i >= 0; i--) {
      formattedString = numberString[i] + formattedString;
      counter++;
      if (counter % 3 == 0 && i != 0) {
        formattedString = '.$formattedString';
      }
    }
    return 'Rp$formattedString';
  }
}

// Extension Product
extension ProductExtensions on Product {
  Product withDiscount(double percentage) {
    var discountedPrice = price * (1 - percentage / 100);
    return Product(name, discountedPrice);
  }
  String get displayInfo => '$name - ${price.toRupiah()}';
  bool get isExpensive => price > 100000;
}

void main() {
  var laptop = Product('Laptop', 15000000);
  var discounted = laptop.withDiscount(10);
  print("=== DATA LAPTOP ===");
  print(discounted.displayInfo);
  print("Laptop mahal? ${laptop.isExpensive}");
  
  var keyboard = Product('Keyboard', 75000);
  print("\n=== DATA KEYBOARD ===");
  print(keyboard.displayInfo);
  print("Keyboard mahal? ${keyboard.isExpensive}");
}

11. Validator Extensions PRAKTEK 2

Validator Extensions adalah penggunaan extension di Dart khusus untuk menambahkan method validasi ke tipe data tertentu (biasanya String, int, atau custom class) sehingga kode validasi menjadi lebih ekspresif, reusable, dan terorganisir.

// Extension validator String
extension StringValidators on String {
  bool get isEmail {
    return RegExp(r'^[\w\.-]+@([\w-]+\.)+[\w-]{2,4}$').hasMatch(this);
  }
  bool get isPhoneNumber {
    return RegExp(r'^[0-9]{10,13}$').hasMatch(this);
  }
  bool get isStrongPassword {
    return length >= 8 &&
        contains(RegExp(r'[A-Z]')) &&
        contains(RegExp(r'[a-z]')) &&
        contains(RegExp(r'[0-9]'));
  }
  bool get isUrl {
    try { Uri.parse(this); return true; } catch (_) { return false; }
  }
}

// Extension validator int
extension IntValidators on int {
  bool get isAdultAge => this >= 18;
  bool get isPositive => this > 0;
  bool get isEven => this % 2 == 0;
  bool get isOdd => this % 2 != 0;
}

void main() {
  var email = 'test@example.com';
  var age = 25;
  var password = 'Pass1234';
  var phone = '081234567890';
  
  print("=== VALIDATOR DATA ===");
  print("Email valid : ${email.isEmail}");
  print("Nomor HP valid : ${phone.isPhoneNumber}");
  print("Password kuat : ${password.isStrongPassword}");
  print("Usia dewasa : ${age.isAdultAge}");
  print("Bilangan genap : ${10.isEven}");

13. Bonus 2 - Prioritas Method Asli vs Extension Hierarchy

Prioritas method adalah aturan di Dart yang menentukan method mana yang akan dipanggil ketika ada nama method yang sama dari sumber yang berbeda (method asli class, extension, atau extension nullable). 📌 Aturan Emas: Method Asli > Extension Non-Nullable > Extension Nullable

📁 bonus2_prioritas.dart
// ==========================================
// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A
// ==========================================

class Greeting {
  String say() => 'Hello from class';
}

// Extension
extension GreetingExt on Greeting {
  String sayExt() => 'Hello from extension';
}

void main() {
  Greeting? obj = Greeting();
  // Method asli class
  print(obj?.say());
  // Method extension
  print(obj?.sayExt());
}

14. Challenge - Media Player Polymorphism

Implementasi polimorfisme pada berbagai jenis pemutar media (Audio, Video, Streaming) menggunakan konsep inheritance dan polymorphism.

📁 media_player.dart
// ==========================================
// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A
// ==========================================

abstract class MediaPlayer {
  void play();
}

class AudioPlayer extends MediaPlayer {
  @override void play() => print('Memutar Audio MP3...');
}

class VideoPlayer extends MediaPlayer {
  @override void play() => print('Memutar Video MP4...');
}

class StreamingPlayer extends MediaPlayer {
  @override void play() => print('Memutar Live Stream...');
}

class Playlist {
  List media = [];
  void add(MediaPlayer player) => media.add(player);
  void playAll() => media.forEach((m) => m.play());
}

void main() {
  var playlist = Playlist();
  playlist.add(AudioPlayer());
  playlist.add(VideoPlayer());
  playlist.add(StreamingPlayer());
  playlist.playAll();
}

📌 KESIMPULAN EXTENSION METHODS

  • 🔧 Methods adalah perilaku bawaan asli yang dirancang dari dalam suatu objek dan memiliki akses penuh ke seluruh datanya.
  • 🔧 Extension adalah cara instan untuk menambahkan fungsi baru ke objek tersebut dari luar tanpa harus membongkar atau mengubah kode aslinya.
  • 🔧 Secara sederhana, Method adalah fitur bawaan pabrik, sementara Extension adalah aksesoris tambahan yang dipasang kemudian.
  • 🔧 Sintaks: extension NamaExtension on TipeData { // method baru }
  • 🔧 Dengan memahami prioritas (Method Asli > Extension Non-Nullable > Extension Nullable), programmer dapat menghindari konflik.
  • 🔧 Extension membuat kode lebih readable, reusable, dan expressive.
